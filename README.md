# CICE Teachers' Day

A cinematic, one-screen Teachers' Day experience for CICE Computer Institute.

## Story order

1. System Boot
2. The Greeting
3. Founding Archive
4. The Classroom
5. The People
6. The Teacher
7. The Impact
8. Final Memory and Thank You

## Important implementation rule

Section 2 uses a labelled QWERTY keyboard. Each greeting character is launched from the matching physical key and travels to its final position at the top of the screen. The keyboard leaves only after the greeting has completely formed.

## Photo assets

The code expects the approved real photographs inside an `assets` folder. The filenames are intentionally descriptive and match the approved sequence in `script.js`.

The text-only website code is complete. Real photographs still need to be copied into `assets/` in the repository because GitHub's text-file editor cannot attach the user's local image bytes directly from this workflow.

## Design rules

- Royal blue with deep navy/black cinematic backgrounds.
- Real photographs are used naturally.
- No generic Teachers' Day template styling.
- No unnecessary hearts, balloons, confetti, or neon overload.
- No invented memories, buildings, dates, or events.
- The experience runs automatically without scrolling.
- The final screen ends on gratitude; there are no buttons or credits.
